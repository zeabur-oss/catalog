---
title: Template catalog
description: Find application templates and choose an application to deploy to a single Namespace.
---

Project members can choose a template to install an application in a single Namespace. Each template pins its image, sets resource requests and limits, and follows the Restricted Pod Security Standard where possible. Templates name required components in `requires`.
