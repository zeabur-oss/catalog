Components are software that cluster administrators install once per cluster. Zeabur Catalog specifies the upstream chart, version, settings, and reasons for each choice by capability (purpose category). The table below lists each component's default status for single-node and multi-node clusters.

Each profile (a set of settings for `single-node` or `multi-node`) uses the following statuses:

- Enabled by default (`recommended`): On by default.
- Optional (`optional`): Available as an option, but off by default.
- Unsupported (`unsupported`): Not available as an option.

The `detection` rules in each component file identify existing installations for the system to reuse.
