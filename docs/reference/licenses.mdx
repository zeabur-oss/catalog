title: Licensing
description: Check the licenses for Zeabur Catalog tools, components, and templates, and the declaration used for contributions.
---

When you use Zeabur Catalog tools, components, or templates, check their license information to confirm the applicable terms. Tools and original files use `Apache-2.0`. Upstream projects, applications, images, and charts retain their original licenses, listed in `metadata.license`.

## Component licenses

Each component's `metadata.license` must use an OSI-approved SPDX license identifier. The allowed identifiers appear in [config/licenses.yaml](../../config/licenses.yaml).

The `optInOnly` list permits the following source-available licenses as exceptions:

| Component | License |
| --- | --- |
| Dragonfly | `BUSL-1.1` |
| Percona Server for MongoDB | `SSPL-1.0` |

These components must be marked as optional (`optional`) or `unsupported` and must not be enabled by default.

## Template license notices

When a template packages software under a source-available license, such as `BUSL-1.1` or SSPL, include the exact license name and a link to the license in a comment at the top of `template.yaml`. Templates must not require users to enter a string to accept a license.

## Contribution declaration

Contributions use the [Developer Certificate of Origin](https://developercertificate.org/). See [CONTRIBUTING.md](../../CONTRIBUTING.md) for contribution instructions.
