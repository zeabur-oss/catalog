## Before you deploy

A catalog template and the zeabur.com template of the same application can differ in version, database and settings. Before you move data across, compare the application version on zeabur.com with the version in the catalog template's `template.yaml`, and read the template's notes in Zeabur under **Before you deploy**.

To check a catalog template's version and the components it needs from a terminal, read it from the [static API](../reference/releases.mdx#the-api). The API holds the latest catalog release, which can be newer than the one your Zeabur bundles. Replace `n8n` with the template ID:

```sh
curl -s https://oss-catalog.zeabur.com/v1/templates/n8n.json | jq -c '[.template.metadata.version, [.template.requires[].component]]'
```

The output is the application version, then the components:

```json
["3.1.0",["traefik","cert-manager","cloudnative-pg"]]
```
