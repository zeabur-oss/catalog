If you run a template on Zeabur, look it up here to find the template to deploy in Zeabur OSS. In Zeabur OSS, open **Add** → **App template** and search for the catalog template's name. Moving the data across is covered in the [Zeabur OSS docs](https://oss.zeabur.com/docs/zeabur/).

## Before you deploy

A catalog template and the Zeabur template of the same application can differ in version, database and settings. Before you move data across, compare the application version on Zeabur with the version in the catalog template's `template.yaml`, and read the template's notes in Zeabur OSS under **Before you deploy**.

To check a catalog template's version and the components it needs from a terminal, read it from the [static API](../reference/releases.mdx#the-api). The API holds the latest catalog release, which can be newer than the one your Zeabur OSS bundles. Replace `n8n` with the template ID:

```sh
curl -s https://oss-catalog.zeabur.com/v1/templates/n8n.json | jq -c '[.template.metadata.version, [.template.requires[].component]]'
```

The output is the application version, then the components:

```json
["3.1.0",["traefik","cert-manager","cloudnative-pg"]]
```
