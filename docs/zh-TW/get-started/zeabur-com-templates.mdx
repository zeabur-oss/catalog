## 部署前

同一個應用程式，catalog 範本和 Zeabur 範本的版本、資料庫和設定可能不同。搬資料之前，先比對兩邊的應用程式版本：一邊是 Zeabur 上的版本，一邊是 catalog 範本 `template.yaml` 寫的版本。接著到 Zeabur 開源版讀範本的**部署前要知道的事**。

也可以在終端機讀取[靜態 API](../reference/releases.mdx#api)，查詢 catalog 範本的版本和需要的元件。API 提供的是最新的 catalog 版本，可能比你的 Zeabur 開源版內建的版本新。把 `n8n` 換成範本 ID：

```sh
curl -s https://oss-catalog.zeabur.com/v1/templates/n8n.json | jq -c '[.template.metadata.version, [.template.requires[].component]]'
```

輸出依序是應用程式版本和需要的元件：

```json
["3.1.0",["traefik","cert-manager","cloudnative-pg"]]
```
