元件是叢集管理員在每個叢集只需安裝一次的軟體。Zeabur Catalog 會依 capability（用途類別）列出採用的上游 chart、版本、設定，以及選擇原因。下表列出各元件在單節點與多節點叢集中的預設狀態。

每個 profile（`single-node` 或 `multi-node` 的設定組合）都用以下狀態標示元件：

- 預設啟用（`recommended`）：預設開啟。
- 選用（`optional`）：提供選項，但預設關閉。
- 不支援（`unsupported`）：不提供選項。

系統會依照各元件檔案中的 `detection` 規則，找出已安裝的元件並重複使用。
