專案成員可以選擇範本，將應用程式安裝到單一 Namespace。每個範本都會固定使用的映像檔，並設定資源要求與上限。可行時，範本也會依照 Restricted Pod Security Standard 執行應用程式。範本也會用 `requires` 列出需要的元件。
