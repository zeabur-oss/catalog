---
title: 添加模板
description: 创建符合模板标准的模板，完成本地检查并提交 Pull Request。
---

参考类似的模板创建文件，添加冒烟测试（smoke check）并完成本地检查，再提交 Pull Request。

<Steps>

<Step>

### 创建模板文件

参考类似的模板，创建 `templates/<id>/template.yaml` 和 `manifests.yaml`。文件结构见[模板文件格式](../reference/template-format.mdx)。

模板 ID 使用小写单词，以连字符连接，长度最多 49 个字符。

</Step>

<Step>

### 符合模板标准

按照[模板标准](../reference/template-standards.mdx)检查模板：

- 固定镜像版本。
- 符合 Restricted Pod Security。
- 为没有登录功能的服务添加入站 NetworkPolicy。
- 设置资源上限。
- 为有状态的数据提供备份。

</Step>

<Step>

### 添加冒烟测试

添加资源条件检查，以及 HTTP 或 SQL 检查，确认应用能响应。

</Step>

<Step>

### 在本地检查

`zeabur-catalog render <id>` 会用测试值渲染模板：`config/e2e.yaml` 中模板声明的输入，以及 `templates/<id>/e2e.yaml` 中的输入。随后用模板 lint 与 kubeconform 检查渲染出的对象。如果某个必填输入在 `config/e2e.yaml` 中没有值，请在 `templates/<id>/e2e.yaml` 中设置。

运行以下命令：

```sh
cargo run -p zeabur-catalog -- check
cargo run -p zeabur-catalog -- render <id>
go run ./tools/cmd/catalog e2e -tier full <id>
```

</Step>

<Step>

### 提交 Pull Request

使用 `git commit -s` 创建附有签署声明的 commit，再提交 Pull Request。

</Step>

</Steps>
