参考类似的模板创建文件，添加冒烟测试（smoke check）并完成本地检查，再提交 Pull Request。

<Steps>

<Step>

### 创建模板文件

参考类似的模板，创建 `templates/<id>/template.yaml` 和 `manifests.yaml`。文件结构见[模板文件格式](../reference/template-format.mdx)。

模板 ID 使用小写单词，以连字符连接，长度最多 49 个字符。

</Step>

<Step>

### 符合模板标准

按照[模板标准](../reference/template-standards.mdx)检查模板：

- 固定镜像版本。
- 符合 Restricted Pod Security。
- 为没有登录功能的服务添加入站 NetworkPolicy。
- 设置资源上限。
- 为有状态的数据提供备份。

</Step>

<Step>

### 添加冒烟测试

添加资源条件检查，以及 HTTP 或 SQL 检查，确认应用能响应。

</Step>

<Step>

### 在本地检查

准备 `values.json`。内容必须是 JSON 对象，并为模板要求的每个输入提供值。

运行以下命令：

```sh
go run ./tools/cmd/catalog validate
go run ./tools/cmd/catalog template lint -values values.json \
  -domain app.example.test -cluster-issuer letsencrypt <id>
go run ./tools/cmd/catalog e2e -tier l2 <id>
```

</Step>

<Step>

### 提交 Pull Request

使用 `git commit -s` 创建附有签署声明的 commit，再提交 Pull Request。

</Step>

</Steps>
