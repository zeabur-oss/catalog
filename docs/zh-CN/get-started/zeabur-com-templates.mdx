## 部署前

同一个应用，catalog 模板和 Zeabur 模板的版本、数据库和配置可能不同。迁移数据之前，先比对两边的应用版本：一边是 Zeabur 上的版本，一边是 catalog 模板 `template.yaml` 中写的版本。然后到 Zeabur 开源版阅读模板的**部署前须知**。

也可以在终端中读取[静态 API](../reference/releases.mdx#api)，查询 catalog 模板的版本和需要的组件。API 提供的是最新的 catalog 版本，可能比你的 Zeabur 开源版内置的版本新。把 `n8n` 换成模板 ID：

```sh
curl -s https://oss-catalog.zeabur.com/v1/templates/n8n.json | jq -c '[.template.metadata.version, [.template.requires[].component]]'
```

输出依次是应用版本和需要的组件：

```json
["3.1.0",["traefik","cert-manager","cloudnative-pg"]]
```
