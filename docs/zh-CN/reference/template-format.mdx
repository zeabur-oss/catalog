模板由 `template.yaml` 和 `manifests.yaml` 组成。你在 `template.yaml` 中定义模板信息，并在 `manifests.yaml` 中使用允许的字段替换。

## template.yaml

以下是精简示例。完整字段请查阅[模板 schema](https://github.com/zeabur-oss/catalog/blob/main/schema/v1/template.schema.json)，模板要求请参考[模板标准](./template-standards.mdx)。

```yaml
apiVersion: catalog.zeabur.com/v1
kind: Template
metadata:
  name: PostgreSQL
  description: PostgreSQL 18 managed by CloudNativePG, with Barman Cloud WAL archiving and scheduled base backups.
  summary: PostgreSQL 18, with backups to S3.
  locales:
    zh-TW: {summary: "PostgreSQL 18 資料庫，備份到 S3。"}
    zh-CN: {summary: "PostgreSQL 18 数据库，备份到 S3。"}
  license: PostgreSQL AND Apache-2.0
  homepage: https://www.postgresql.org/

requires: [databases/cloudnative-pg]

services:                         # the workloads in manifests.yaml
  - name: postgresql
    securityProfile: restricted   # or baseline
    ports: [{name: postgresql, port: 5432}]
    resources: {requests: {cpu: 100m, memory: 256Mi}, limits: {cpu: "1", memory: 1Gi}}

inputs:
  - name: backupDestination       # the person installing gives it
    description: Dedicated S3 bucket and unique prefix for this cluster.
    required: true
    validation: {pattern: '^s3://[a-z0-9][a-z0-9.-]+/[A-Za-z0-9/_-]+$'}
  # From n8n: the installer generates this value into a Secret.
  # - name: encryptionKey
  #   generate: random
  #   secret: {name: n8n-secrets, key: encryption-key}

security: {...}      # summary, risks with mitigations, unauthenticated services
smoke: []            # resource condition, then an HTTP or SQL check
```

## manifests.yaml

`manifests.yaml` 只允许字段替换，规则如下：

- 可用的替换字段只有 `{{ .Namespace }}`、`{{ .Domain }}`、`{{ .ClusterIssuer }}`，以及非自动生成输入值的 `{{ .Inputs.<name> }}`。
- 不允许条件、函数、管道或空白裁剪标记。
- 未提供的输入值使用 `default`；没有 `default` 时，值为空。
- 模板需要选项时，使用设有 `default` 的输入字段。
- 渲染后的对象必须引用 Secret，不得包含自动生成的值。

渲染前的检查和每个对象都会加上的 label，见[客户端如何渲染模板](template-clients.mdx)。
