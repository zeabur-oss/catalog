组件是集群管理员在每个集群安装一次的软件。Zeabur Catalog 按 capability（用途类别）列出采用的上游 chart、版本、配置和选择原因。你可以通过下表查看各组件在单节点与多节点的默认状态。

各 profile（`single-node` 或 `multi-node` 的配置组合）使用以下状态：

- 默认启用（`recommended`）：默认开启。
- 可选（`optional`）：提供选项，但默认关闭。
- 不支持（`unsupported`）：不提供选项。

各组件文件的 `detection` 规则会找出现有安装，供系统复用。
